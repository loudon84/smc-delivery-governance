# ADR-004 — Repo Work Package

Repo Work Package 是中央治理与项目本地交付之间唯一正式连接器。它描述仓库级 Outcome，不切片到文件或函数。

**Status:** APPROVED

只包含 Outcome、Repository、Role、Global Change IDs、Dependencies、Contract Inputs/Outputs、Acceptance、Evidence Required。

禁止包含 exact file、symbol、helper、local Todo slicing。

领域定义见 [[domain/entities#Repo Work Package]]。
